## Ejecutar el portafolio

Requiere Node.js y npm.

1. Instalar dependencias: npm ci
2. Iniciar el servidor de desarrollo: npm run dev
3. Crear la versión de producción: npm run build

El código Android de Crypto Alert está en proyectos/crypto-alert. La extensión de IP Monitor está en proyectos/ip-monitor-extension.

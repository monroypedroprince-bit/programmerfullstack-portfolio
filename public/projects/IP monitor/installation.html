IP Monitor

Browser extension

Install IP Monitor

Use IP Monitor in Chrome, Edge, Brave, or Opera to keep checking your public IP in the background and receive a browser notification when it changes.

1

Download and extract the ZIP

Download the extension package and extract it into a folder on your computer. Keep the files together so the browser can read manifest.json.

2

Open your browser's extensions page

Enter chrome://extensions, edge://extensions, brave://extensions, or opera://extensions in the address bar.

3

Load the extension folder

  1. Turn on Developer mode.
  2. Select Load unpacked.
  3. Choose the extracted IP Monitor folder that contains manifest.json.
4

Start monitoring

Open IP Monitor from your browser's extension menu, start monitoring, and enable sound alerts if you want an audible notification.
